A free planner for writers: outlines, characters, and short courses. It works offline, and your work stays on your device.

Android

For this device

For Android phones and tablets.

Download for Android
How to install
  1. Download the file on your phone or tablet, then open it.
  2. Your device may say it can't install apps from your browser. Choose Settings, turn on Allow from this source, then go back.
  3. Choose Install.

Using Brave on Android? If the download asks you to sign in to GitHub, open this page in Chrome instead. No account is needed.

Windows

For this device

For Windows 10 and 11 computers.

Download for Windows
How to install
  1. Open the file you downloaded.
  2. If you see Windows protected your PC, choose More info, then Run anyway.
  3. Follow the steps to finish installing.

Latest update

Version 0.9.1

November 1, 2026

New

  • Storybones is now an app for Windows computers and Android phones and tablets, downloaded from the Storybones website.
  • Your work is saved in a file in the app’s own folder on your device, so clearing a web browser can’t touch it. Work you saved before moves over by itself the first time you open this version.

Improved

  • Backups and exports ask where to save the file.
  • Links to other websites, like Ko-fi, open in your web browser.

Fixed

  • On Android, Storybones opened to a blank screen.

Every earlier update is in the app, under What’s New.
