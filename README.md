# Storybones

The website for **Storybones**, a free planner for writers: outlines,
characters, and short courses. It works offline, and your work stays on
your device.

**Visit:** https://dnpart.github.io/storybones

The Android and Windows downloads are on this repository's Releases page.
This repository holds only the website; the app's source code isn't public.
